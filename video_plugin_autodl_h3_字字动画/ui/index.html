AutoDL MiniMax-H3 视频生成

令牌获取：autodl.art → 令牌管理（分组选择 ComfyUI） 打开令牌管理
自动规则：有参考音频 → 多图多音频工作流；有首帧+尾帧 → 首尾帧工作流；有参考图/首帧 → 多图参考工作流；纯文字 → 文生视频。时长超过10秒自动切换15秒版工作流。
注意：首尾帧工作流需要分镜同时设置首帧和尾帧图；多图参考工作流需要至少1张参考图。
当前工作流不支持的分辨率会自动降级（如1080p→768p同方向）。480p/768p 促销价￥0.01/秒，1080p按工作流不同约￥0.10/秒。
跟随分镜时取分镜的时长设置；固定时长则始终使用右侧数值（1-15秒，超出工作流上限自动截断）。
左：最大边长像素；右：JPEG质量。参考图会自动压缩并转为 data URI 提交，减小请求体积、提升上传成功率。
左：查询间隔秒数；右：单任务最大等待秒数。10秒视频实测约2分钟生成完成。
使用说明：
1. 分镜的参考图（最多9张）、首帧/尾帧、参考音频（最多3段）会自动映射到 H3 工作流对应槽位；
2. 音频仅支持 MP3/WAV/MP4/FLAC，图片支持 JPG/PNG/WebP（自动转码为JPEG）；
3. 计费按视频秒数计算，任务提交后立即开始计费，失败任务不扣费；
4. 生成结果为 MP4，自动按分镜规范命名保存到项目目录。
